# Faculty Credentialing Form

The Faculty Credentialing Form is the page Bossier Parish Community College's academic deans use to document each faculty qualification determination under the College's Faculty Qualifications and Credentialing Policy, until the College's system of record for credentialing is in place. It runs entirely in the dean's browser. It stores nothing, and nothing a dean enters or attaches is sent to this site. Each determination ends in one PDF packet saved to the dean's own computer, which the dean uploads to the Faculty Credentialing library in SharePoint.

`index.html` is built from the form's source, kept by the Office of Academic Affairs. Edit the source and rebuild rather than editing this file by hand.
